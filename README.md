# Lumi AI ✦

Lumi is a playful personal AI shell for learning, creating, planning, and growing ideas.

## Current prototype

- Chat, Learn, and Create modes
- Spaces for different parts of your life
- User-controlled memory toggle
- Responsive mobile navigation
- Local demo conversation history
- Simulated responses while the secure AI backend is being developed

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Every push to `main` runs the GitHub Pages deployment workflow. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

> Never place an AI provider API key in this repository or in browser-side code.
